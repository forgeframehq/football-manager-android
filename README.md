# Football Manager Android

Simple football manager game for Android.

## Features
- Generate a squad of 11 players with ratings
- View your squad
- Simulate matches against random opponents
- Track wins/losses
- Advance seasons with slight squad improvements

## Installation
Download the APK from the Releases section (or the attached file) and install on your Android device (enable unknown sources if needed).

## Building from source
Requires Android SDK command-line tools, platform android-34, build-tools 34.0.0.

See the source in `src/com/forgeframe/footballmanager/MainActivity.java` for the game logic.

## Note
This is a basic prototype. Expand with more features like transfers, tactics, league tables, etc.
